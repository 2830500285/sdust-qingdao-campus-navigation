# Android WebView Shell

This is a minimal Android shell for the hosted campus navigation site.

- App URL: `https://2830500285.github.io/sdust-qingdao-campus-navigation/`
- Package: `io.github.sdust.navigation`
- Output APK: `output/apk/sdust-navigation-webview.apk`

The project is compiled directly with Android SDK build tools from `cache/android-toolchain`.
